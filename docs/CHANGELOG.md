# Changelog

## Unreleased

## v1.0.0 - 2026-11-24

- Send voice over both authorized Wi-Fi and BLE attachments when available, merging and deduplicating audio before playback. A surviving link can carry the recording without restarting input.
- Recover short single-link losses with negotiated, bounded audio history and missing-block repair; retry temporary Wi-Fi/BLE send pressure without accumulating seconds of old speech.
- Stabilize link selection against brief jitter, preserve trailing speech and queue Enter until voice output finishes. Stop input safely on full disconnection or sleep; never resume recording automatically.
- Scope voice timing activity to recording and release repair state and temporary history after use. Older peers retain their existing voice protocol; install the matching app and firmware for the new recovery behavior.
- Known issue: Internet radio can still stutter when delivery changes to BLE and retransmissions accumulate. This release does not include a radio scheduling fix.

## v0.9.1 - 2026-11-23

- Suspend Bluetooth scanning/connections, LAN retries, audio and quota polling when the computer sleeps, without waiting for network or audio cleanup on the sleep notification thread.
- Resume on system wake independently of display state; keep manual disconnect intent and prevent stale callbacks from reopening or disconnecting a newer session.
- Release held input keys before sleep, cancel pending radio-list writes before closing their transport, and allow sleep-interrupted quota queries to retry after wake without changing successful polling intervals or failure backoff.

## v0.9.0 - 2026-11-18

- Add automatic remaining-quota cards for Codex, Claude Code and OpenCode Go using existing Agent logins. Collect during recent activity; hide unavailable or stale observations without interrupting the user.
- Place quota cards before the four weather pages with one consistent page counter. Show three independent percentage windows together when available, including Go’s five-hour, weekly and monthly allowances.
- Add **Connect your own Agent** in the desktop app, with a copyable prompt for both local task alerts and quota callbacks. Custom sources keep their own names and support percentage windows or independent monetary balances.
- Improve Bluetooth data delivery by keeping unrelated subscription changes from disabling the application notification channel.

## v0.8.4 - 2026-11-17

- Connect over Bluetooth or Wi-Fi with the same voice, Enter, reminders and radio features. Bluetooth supports offices where the device cannot join the network.
- Discover each device once across both links and approve connections on its screen instead of entering a pairing code. Confirm a computer handover on the device.
- Decode radio on the computer and stream it over either link; improve buffering, reconnection and voice interruption/resume. Use the matching firmware and Mac app together.
- Start a new device with Bluetooth or optional Wi-Fi setup. Improve hotspot discovery responses and show a ten-second manual-browser fallback.
- Wake a dark screen before menu or connection-confirmation actions, while retaining direct Home voice and Enter gestures.
- Simplify input setup, direct BlackHole download, input-method settings and Agent installation guidance.

Local Intel/device acceptance includes voice, Enter, radio/resume, BLE re-pairing, phone Wi-Fi, installed reminder hooks and a fresh-start connection. Power/battery, clean-system and minimum-macOS/Apple Silicon physical testing, and physical multiple-computer/device acceptance remain outside this release's completed local scope. Packages use ad-hoc signing and are not Apple notarized.

## v0.8.3-vibe-companion - 2026-11-10

First public Vibe Companion release for FoloToy AI Passport, with a native macOS companion app.

- Wireless hold-to-talk input and a dedicated Enter action, available alongside Pomodoro or radio.
- Local Agent integrations for Codex, Claude Code, OpenCode, DeepSeek Harness, ZCode, Gemini CLI and Qwen Code, with compact screen and sound alerts and per-session duplicate suppression.
- Focus/rest phases that wait for the next manual start, multi-page weather, light/dark themes and scheduled theme switching.
- Desktop station search, custom-stream checks and list ordering; radio yields to voice and reconnects afterwards.
- Saved Wi-Fi networks with automatic reconnection, automatic available-port discovery and synchronized device settings.
- Menu-bar app, on-demand standby/heap diagnostics, bilingual setup guides and universal Apple Silicon/Intel DMG and ZIP packages.

Physical Intel and clean-machine installation remain unverified. Packages use ad-hoc signing and are not Apple notarized.
