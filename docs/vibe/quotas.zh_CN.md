# Agent 额度

额度采集沿用现有 Agent 集成按钮，不增加额度登录、API Key 表单、浏览器 Cookie 导入或钥匙串授权。采集失败只记录本机诊断，不出现错误卡片，也不影响 Agent 提醒。

## 已实现来源

- Codex：由桥接器启动有时间和输出上限的 `codex app-server` 子进程，复用已有 ChatGPT 登录，读取 `account/rateLimits/read`，并在查询前后核对账号。不创建对话，不发送模型请求。只有每周窗口时就只展示每周窗口；API Key 登录不作为订阅额度。
- Claude Code：集成包装官方状态栏命令，在使用期间转发 `rate_limits`，保留原命令输出。重复重绘沿用原观察标识和采集时间，桌面端重启后也不会续期。只转发规范化数值，不转发原始状态栏载荷。已有集成可点“更新集成”；移除时仅在状态栏仍由我们包装的情况下恢复原配置对象。
- OpenCode Go：已安装的插件解析 Agent 当前选中的 OpenCode 连接，读取官方 Go 额度接口，分别保留五小时、每周、每月的剩余比例和重置时间。凭据不离开 Agent 进程，也不发送给桥接器。
- 自定义 Agent：点击“接入自己的 Agent”准备 helper，复制同时包含提醒和额度的接入提示词。[本机回调协议](agents-custom.zh_CN.md)。
- 其他提醒集成继续可用。没有验证一键接入路径和真实剩余额度的来源暂不启用，本机 Token 数量不替代额度。

## 活动与频率

Codex 集成回调提供活动信号。启动和恢复时，还会在选定 `CODEX_HOME` 的今天、昨天目录中，各检查最多 64 个会话文件的修改时间，不读取对话内容。文件最近修改只代表活动线索，不证明模型仍在运行。连续十分钟没有活动后停止补充查询；明确的完成、结束回调会屏蔽更早的文件活动线索。

首次活动可触发查询；同一来源合并请求，在界面及网络队列之外运行，正常两次尝试至少间隔五分钟。失败后退避到十、二十分钟。额度查询成功本身不会被算成 Agent 活动。Claude 接收新的观察数据，不轮询已认证服务；频繁更新会合并成最新样本，按五分钟节奏发送，保留原采集时间。

## 有效期与归属

展示有效期为 930 秒，即三个正常查询周期加三十秒调度余量。只有新的成功观察才能开始有效期。网络重试、重连补发保留原观察标识和剩余有效期；设备去重重试并拒绝旧观察。每个额度窗口到达服务端报告的重置时间后，也会退出展示，不自行推断已恢复满额。

额度是临时状态：切换授权或解除配对会清除，短暂链路中断不会延长有效期，不写入设备 NVS。凭据留在电脑端，协议只携带不透明归属摘要及展示字段。

## 展示协议

固件能力 `agentQuota: 1` 接受 schema 1 的已认证 `quota.cache`。最多七个来源卡片，每张最多四项。名称、标签使用有长度上限的可打印 ASCII；固定说明和标准周期名称使用已验证中文字库。未知数据类型、非法数值静默拒绝，每条消息不超过现有 1536 字节控制上限。

通用模板包括单项比例、两个独立周期、分模型分页、独立币种余额。三个比例周期可在同页紧凑展示；其他组合每页两项，更多内容另起一页。金额不跨币种相加，也不变成百分比。超大金额在设备以明确的近似缩写显示，桌面端保留完整记录值。大于零的小比例不会被显示成零。

有效额度页排在最前面，启用天气时后面接四页天气。两者共用全局页码和总页数：一页额度加四页天气显示 1/5 至 5/5。亮屏且空闲的首页每八秒轮播天气和有效额度；短按设置键手动翻页并重新计时。语音、计时器、收音机、连接确认及 Agent 提醒优先。轮播不重置息屏时间，也不唤醒黑屏。过期或没有数据的额度不占页面。

## 验证范围

主机测试覆盖仅每周窗口、零值、缺项、协议非法字段、重试不续期、重置失效、动态分页、私有状态栏备份与恢复、重复重绘和轮播暂停。固定版本的 LVGL 渲染器检查真实字体下的深浅主题和布局边界。硬件与真实账号验收单独报告；Claude 合成数据测试不等于真实 Claude 账号验收。
