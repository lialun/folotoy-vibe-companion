# Vibe 伴侣设计规范与约定

本文定义产品的交互、视觉和工程约定，供新增功能与代码评审使用。
[实现记录](implementation.zh_CN.md)保留历次实验和确切验证结果，其中的历史检查点不覆盖本文约定。
仓库工作流程与 BSP 边界遵循 [AGENTS.md](../../AGENTS.md)。

## 1. 产品优先级

Vibe 伴侣首先是**语音输入伴侣**，围绕核心提供信息与轻量应用。优先级依次为：

1. 可靠、快速可用的语音输入，以及符合操作意图的回车。
2. 看得清的信息和可预期的三键操作。
3. 在 ESP32-C3 内部 RAM 上稳定运行。
4. 节能，同时保障语音可靠性和稳定播放。
5. 符合同一套交互体系的扩展应用。

开机直接进入首页，不增加展示页或启动器。不沿用上游硬件测试界面做产品外壳。
复用官方 BSP 和独立库逻辑，产品界面放在 `main/vibe/`。

## 2. 设备的心智模型

首页相当于桌面：上方保留紧凑的语音状态，下方只有一个活动内容模块。
默认模块展示天气，番茄钟、收音机替换它；**天气、番茄钟、收音机互斥**。

语音是在首页三个模块内均可调用的抢占服务，语音期间收音机静音。
设置、配网、确认页是独立页面，使用各自按键含义，不继承首页的语音／回车映射。

计时状态独立于页面切换。进入设置或退出确认页不会暂停番茄。
运行或暂停中的番茄切换到收音机，需要直接确认；先结束番茄，再启动收音机。
未来模块必须说明进入、运行、中断和退出状态。

## 3. 实体键与手势

从上到下分别为**上键、下键、设置键**。下键在机器中间，设置键在最下方。
BSP 把设置键称为 `OK`，产品文案统一叫设置键，不使用未解释的“中键／底键”。

| 场景 | 上键 | 下键 | 设置键 |
| --- | --- | --- | --- |
| 首页默认模块 | 按住语音，松开结束 | 短按回车；长按进入番茄待开始 | 短按翻天气页；长按功能 |
| 番茄待开始 | 按住语音 | 短按回车；长按直接退出 | 短按开始；长按功能 |
| 番茄运行中 | 按住语音 | 短按回车；长按退出确认 | 短按暂停；长按功能 |
| 番茄已暂停 | 按住语音 | 短按回车；长按退出确认 | 短按继续；长按功能 |
| 下一阶段待开始 | 按住语音 | 短按回车；长按直接退出 | 短按开始下一阶段；长按功能 |
| 收音机 | 按住语音，松开恢复之前的收听意图 | 短按回车；长按退出确认 | 短按下一台；长按功能 |
| 退出／切换番茄确认 | 短按取消 | 短按退出或切换 | 无操作 |
| 退出收音机确认 | 短按取消，保留收听意图 | 短按停止并退出 | 无操作 |
| 功能／设置浏览 | 短按上一项 | 短按下一项 | 短按进入／编辑；长按返回 |
| 修改设置值 | 短按增加／上一个选项 | 短按减少／下一个选项 | 短按完成；长按离开编辑 |

按下、保持、松开构成**一次手势**。长按之后的松手不再触发短按。
长按下键不能额外回车，也不能在进入页面的同一次手势中立刻退出。
两次短按仍是两次明确操作，本版不引入双击操作体系。录音期间忽略其他首页动作，直到上键松开。

首页长按下键相当于应用快捷键：默认模块进入番茄，应用内退出当前应用。
待开始页进入后，右栏立刻改为退出图标。设置键短按承担当前应用的主要动作。
收音机短按设置键专门换台，长按下键打开退出确认页。确认页显示期间及上键取消时，
保留原音频流与当前电台；只有短按下键确认才停止并退出，进入页的长按松手不能确认。
按键窄栏与直接选择沿用番茄退出页。功能菜单只保留设备设置与收音机，
不增加暂停／继续收听选项；语音抢占时的自动暂停与恢复仍保留。

## 4. 番茄钟流程

```mermaid
stateDiagram-v2
    Default --> Ready: Hold DOWN
    Ready --> Running: Tap SETTINGS
    Running --> Paused: Tap SETTINGS
    Paused --> Running: Tap SETTINGS
    Running --> NextReady: Deadline and alarm
    NextReady --> Running: Tap SETTINGS
    Ready --> Default: Hold DOWN
    NextReady --> Default: Hold DOWN
```

图中 Default 为默认模块，Ready 为待开始，Running 为运行中，Paused 为已暂停，NextReady 为下一阶段待开始。

- 进入待开始页不自动计时，之后短按设置键才开始。
- 剩余时间是视觉主角，同时明确当前是专注还是休息及其时长。
  电脑端修改页同样需要清晰展示专注和休息时长。
- 使用单调时钟截止时间；息屏、语音、切页面、换主题不改变倒计时。
  修改偏好不重置已经运行的阶段。
- 到点播放现有提醒音，完成反馈显示 10 秒，之后保留下一专注／休息阶段待开始。
  下一阶段必须按键开始，不自动开始，也不自行退出番茄。
- 打开退出页时保持倒计时及运行／暂停状态。上键取消保持状态，下键结束。
  两个选项直接对应两个按钮，不使用上下选择后再确认的菜单。
- 待开始和下一阶段待开始可以长按直接退出，因为没有活动倒计时。
- 文案只保留状态、时间、明确选项，删除说明性口号和退出后展示什么默认内容的描述。

## 5. 信息与反馈

语音状态区分未联网、未配对、电脑不可用、准备未完成、就绪、输入中、可重试音频异常。
一次音频异常不能永久禁用回车或阻止下一次录音尝试。番茄钟无需电脑也可计时。
语音不可用或断连时，不在本地积攒录音等待以后上传。

天气分四页：当前天气、未来六个整点、空气与风力、三日预报。
短按设置键手动翻页，时间流逝不自动换页。保留当前阅读页，下一次唤醒恢复默认页。
翻页只读缓存，不触发网络请求或 Flash 写入。

逐小时温度、降雨概率和降水量按相同的时间列对齐，缺失温度不连线。
三日预报左侧文字、右侧较大天气图标。图标覆盖已知天气码、昼夜变化，并提供未知类型兜底。
风力使用级数；明确标记数据源的**美标 AQI**，PM2.5 单位为 µg/m³。
缺失或过期值显示横线，不冒充为零；今日最高 UV 同时显示文字等级。
详细数据与新鲜度规则见[使用指南](README.zh_CN.md)。

收音机显示电台、连接／播放／停止／失败状态和列表位置。当前电台用 20 px 正文居中，
下一台用 16 px 辅助字号，长名称有界截断；不用虚构的 MHz 数字表达列表位置。
调谐刻度直接绘制，换台时仅名称区域纵向滑动 200 毫秒，播放时保持静止。
顶部语音与右侧按键栏不参与滑动。连续换台替换当前动画，不排队；语音、息屏、
换页与主题重建先取消动画。复用标签及字体，不新增整屏画布、透明图层或任务。
Mac 在添加自定义源前检测音频；“我的电台”仅显示名称和排序操作，不展示成功播放标记，
检测不保证今后一直可用。空列表和不支持的流需要明确反馈。

## 6. 设备视觉规范

### 画布与信息层级

屏幕为 **240 × 320 像素**，物理尺寸小，外壳遮挡圆角明显。
按原生分辨率设计并在真机检查，电脑放大图不能证明可读性或边缘安全。

- 使用连续画布，不把语音区和功能区套进两个装饰卡片，不保留大块应用标题区。
- 顶部状态区域约 24 px，文字和图标为 16 px，给外壳圆角保留明确的上方及左右内缩。
  展示 Wi-Fi 格数、日期时间，电池图标左侧紧邻电量百分比。
  数字变化时固定图标位置，为 `100%` 留足空间，电量计不可用时显示 `--%`。
  复用现有电池标签，开机、每次亮屏采样，持续亮屏每分钟更新；息屏时不读取电量计，
  不新增轮询任务或定时器。
- 语音保持紧凑状态行，左侧约 28 px 的波形与文字协调。
  就绪只显示一行并垂直居中，异常／录音可显示两行；无副标题时不能保留空行。
- 剩余区域优先用于天气、清晰的倒计时或电台信息。
- 右侧按键栏约 16 px 宽，当前首页文字从 `x=221` 开始。
  位置跟随实体键，不把屏幕等分为三段。新坐标必须检查真机圆角遮挡。

### 字体与图标

中文正文使用维护中的 **20 px** 字体，辅助信息和按键标签使用 **16 px**。
主要温度／时间在空间允许时使用 36／48 px 数字。不能为了装饰内容缩小正文。
字间距需要有意压紧，当前中文标签字间距为 -1 px，按键栏使用单独的紧凑行距。

语音波形与文字协调，不能过大。番茄入口使用计时器符号，应用内改为退出符号。
桌面品牌使用伴侣／轨道图形，不用麦克风形状充当应用图标。

增加中文前检查字形覆盖、控件字体、符号回退和动态名称，不能隐藏缺字方框。
同时验证长短标签、缺失值、三位数字和电台名。

### 颜色与主题

使用语义色变量，不随意给单个控件增加独立颜色：

| 用途 | 暗色 | 亮色 |
| --- | --- | --- |
| 背景 | `#14232E` | `#C6C1AD` |
| 主要文字 | `#F0EBDD` | `#1B2529` |
| 辅助文字 | `#A8BBC2` | `#3F4B50` |
| 语音 | `#51DFC4` | `#005749` |
| 专注 | `#FFB47D` | `#8C2C0C` |
| 休息／回车 | `#8CC9FA` | `#004E96` |
| 天气强调 | `#F2CB73` | `#654600` |

浅色主题用中性的主要／辅助文字，不给每个数值分配相近的深色。当前温度与普通设置
数值使用主要文字色；语音、专注／休息、UV 和 AQI 保留语义色并配明确文字。
设置选中行使用中性文字，编辑继续由既有数值反色、箭头及描边表达。即使实屏色相
接近，也能通过字号和位置识别层级。文字色在实际背景上经 RGB565 量化后的目标
对比度至少为 4.5:1；这是渲染颜色检查，不是 LCD 实物测量。

矢量图形使用更鲜明的青绿 #00765D、蓝色 #0965AD、
橙色 #B54716 和赭金 #936100。应用于既有语音／天气图标、按键标记、调谐指针、
进度和图表线条，不让小字跟随图标提亮，不增加图像绘制表面。

亮色是低刺激暖灰画布，不是纯白面板。颜色辅助文字和符号，不能独自表达状态或可用性。
LCD 观感可能与 RGB 渲染图不同，两种主题均需在正常亮度下真机验证。

支持暗色、亮色、定时切换，默认 08:00 亮色／21:00 暗色。
时段由设备执行并支持跨午夜，尚无有效时间时自动模式使用暗色。
主题不改变亮度、计时状态或播放。自动模式在开机、首次取得有效时间与唤醒后直接
按当前设备时间计算，不依赖经过切换点，不保存上一次算出的亮暗结果。
彻底断电后若设备时钟无效，Wi-Fi 获得地址后通过 SNTP 获取 UTC。
保留客户端校时；客户端更新时区前使用已保存时区。手动暗色／亮色不执行自动时段。

设备系统时钟是唯一的日历时间来源；SNTP 和已认证客户端都只是校准该时钟，不各自
提供一套界面时间。已有有效本机时间时立即使用；校时后重新计算依赖日历时间的
显示与主题，不重启设备、应用或番茄钟。持续时长使用设备的单调时钟，避免日历
时间修正改变已进行的专注时长。

联网校时由现有网络任务和 SDK TCP/IP 服务管理。仅在时间无效、未录音／配网且
空闲堆至少 20 KiB 时开始。每次尝试一个服务器，截止 12 秒；失败轮换阿里云、
Cloudflare、pool.ntp.org，重试间隔依次为 5 秒、1 分钟、5 分钟，上限 15 分钟。
尝试期间，息屏时临时最多每秒检查一次完成状态。时间有效、Wi-Fi 断开或开始录音／
配网时停止并释放 SNTP 服务。成功后不保留周期校时请求、定时器或完成状态轮询。
不新增专用任务、信号量、亮屏或 Flash 时间戳写入。无互联网且无客户端时保持时间
不可用、自动主题使用暗色，等待有效来源；不把已存时间戳冒充当前时间。

音频使用期间允许校验后的纯音量配置更新，其他改动仍受限制。沿用现有保存、版本
通知与确认流程；播放任务在下一帧 PCM 应用新音量，不重启流，不从配置路径改变
录音期间静音的输出。

### 统一按键栏与编辑状态

每个页面使用同一侧按键栏，包括设置与确认页。点表示短按，加长横线表示长按，
手势标记和短标签保持一组。不再在页底重复一整套按键说明，不可用操作减弱显示。

编辑必须改变左侧选中值本身：行描边、数值反色实底、方向箭头。
只有右栏变化不足以说明正在编辑。文案使用简洁状态与有用错误，
删除重复说明、营销文案和没有额外含义的就绪圆点。

## 7. 桌面端交互

连接、配对和设备操作使用“电脑／客户端”等通用称呼；只有平台特有功能和要求才写操作系统名称。
通用文案不代表已经支持其他平台，当前客户端仅支持 macOS。

macOS App 主要是菜单栏工具。打开窗口时可显示 Dock 图标；点红色关闭按钮后隐藏 Dock 图标，
接收程序继续运行；只有退出 App 才停止。侧栏整行均可点击。
App、Dock、菜单栏使用一致的伴侣品牌图形。

设置按用途分组，展示明确的单位、范围、保存结果。较长解释放在帮助提示里，
例如麦克风增益的作用和何时调大／调小。输入法提示说明按住说话兼容条件与快捷键冲突风险。
连接和番茄页下方不重复设备按键教程，不在固定页脚解释关闭窗口行为。
专注与休息时长并列展示。

收音机采用**电台库＋我的电台**：推荐、名称搜索、自定义地址检测，汇入最多 20 台的有序列表。
搜索行依次为“搜索电台”输入框、“中文”复选框和“搜索”按钮。推荐的 15 台也按相同顺序作为
新设备的初始列表；升级保留任何已保存列表，包括用户主动保存的空列表。
搜索默认勾选中文，取消勾选即不限制语言；名称可以留空。每页 10 条，隐藏目录标记失效的台，
按票数降序，不额外限制国家或码率。可重排、删除、保存空列表；检测失败保留输入。
客户端管理列表，不控制设备播放。

macOS 界面、按键发送及网络线程共用主线程更新的快捷键权限快照。
工作线程不能在退出流程等待它结束时，再同步等待主线程查询权限。
授予快捷键权限后，客户端回到前台时重新检测。若当前进程仍显示未授权，则在用户主动申请权限并返回后，
或同一可执行文件的新进程确认已授权时，自动重新载入一次。子进程也可能继承缓存的拒绝状态。
等待正在执行的操作结束后才重载；新进程必须通过实际快捷键权限检查才能显示就绪。用私有、短期、一次性恢复文件保留未保存的
设置、电台顺序、表单与页面；先关闭旧 UDP 接收，再启动新进程。每轮最多自动重载一次，避免循环。
不能用其他权限检查代替快捷键权限，也不能发送测试按键来猜测授权状态。

## 8. 配置与连接

手机热点配网**只配置 Wi-Fi**，使用无密码 `Vibe-Setup-...` AP 和自动门户。
连接且保存成功后自动关闭 AP，不再要求第二次确认。
日常设置通过正常局域网修改，不需要重新切入设备热点。

最多保存五个 Wi-Fi，只在手机门户管理。已保存与附近网络分组显示，复用已存密码但不向浏览器返回密码，
支持修改密码和忘记网络。同名网络只在连接且保存成功后替换凭据。
满额时需要明确忘记旧网络，不自动覆盖；忘记只删除保存记录，不中断当前连接。

每次开机／断线，先尝试上次成功网络，再尝试其余每个已保存网络，包括隐藏或扫描未发现的 SSID。

## 9. 资源所有权与功耗

一个音频任务统一拥有麦克风、编解码硬件、提醒音和收音机，按键回调只投递事件。
语音服务状态及其 **3,200 字节 PCM 缓冲从启动开始保留**，收音机播放时也保留。
保留 RAM 不代表麦克风持续供电，音频空闲时休眠编解码芯片。

天气使用一次性工作任务。HTTP／TLS、响应正文、解析资源释放后，由其他任务删除完成的工作任务，
回收其 **8 KiB 栈**。音频先取消并等待天气任务完全清理，再使用资源。
仅仅休眠或挂起任务不能回收它的栈。

收音机仅拥有可释放的压缩 FIFO。语音先结束会话并释放缓冲再录音；只有仍有收听意图才恢复。
电脑负责源连接、解码和较大的有限缓存。

每块内存必须有唯一所有者、生命周期和失败规则：

| 资源 | 所有者／生命周期 | 释放与失败规则 |
| --- | --- | --- |
| 语音 PCM，3,200 字节 | 音频服务／应用整个生命周期 | 启动预留，启动失败回滚，不借给其他模块 |
| 核心任务栈，合计 33 KiB | 主程序、音频、网络、LVGL／应用整个生命周期 | 测量最坏路径后调整，不为每个页面增加常驻任务 |
| LVGL 池 26 KiB＋显示 DMA 9,600 字节 | UI／应用整个生命周期 | 模块对象在池内重建，区分 DMA 与普通堆的分配要求 |
| 天气栈 8 KiB 与 HTTP／TLS／正文／解析工作区 | 一次性天气任务／一次更新 | 音频使用前取消、清理、由其他任务等待删除；分配失败延后天气 |
| 电台压缩 FIFO，15,704／23,556 字节 | 音频所有者／一次收听会话 | 断开回调后释放；语音、退出、切换、失败均清理；保留 16 KiB 余量 |
| Wi-Fi 凭据表，487 字节 | 网络服务／应用整个生命周期 | 最多五组，独立互斥锁；在已有工作栈临时编码最多 491 字节载荷，先保存再替换；局域网／门户读取不返回密码 |
| 已保存电台列表 | 目录／应用整个生命周期 | 按 `12 + 306 × 数量` 字节分配，最多 6,132 字节，不常驻固定 20 槽位；NVS 只存实际名称／地址与结束符，兼容旧 16 槽位存储 |
| 电台列表传输暂存 | 配置事务／有界传输周期 | 仅音频空闲时按传入数量分配，音频开始前取消；原子提交直接转移所有权，不再复制整表；失败保留原表，放弃的事务到期释放 |

新增功能必须记录**同时发生时的内存峰值**，包括库内部申请、任务栈、DMA 和临时副本。
按真实生命周期计算重叠，不能把互斥状态简单相加，也不能漏掉后台任务。
部分初始化失败必须释放已经取得的资源，不释放其他所有者仍在使用的缓冲，不删除仍使用缓冲的任务。
反复进入退出和语音抢占时记录空闲堆、最大可用块、最低空闲堆和栈高水位。
单次申请成功不代表预算充足。更改资源策略时，必须覆盖生命周期、申请失败、反复清理测试和真机回归。

收音机由当前电脑通过已选 Wi-Fi 或 BLE 链路转发。电脑拉取并解码 MP3／AAC／HLS，
转换为 24 kHz 单声道，再发送独立的 50 ms IMA ADPCM 块。设备不保留收音机 HTTP／HLS／TLS、
AAC／MP3 解码器、读取任务或独立 PCM 工作区；非录音时复用常驻的 3,200 字节语音 PCM。
电脑必须保持唤醒、联网并运行客户端；通过 BLE 收听时可以关闭设备 Wi-Fi。

电脑最多缓存 200 个编码块，约 118 KiB／10 秒，满后阻塞生产者。

语音、退出、换台、电脑／链路切换或失败时停止进程、待发音频和接收会话；
松开语音后以新会话恢复直播。连接／读取和进程退出均有限时，不能为了快一点恢复就保留大块内存。

保留必须驻留的中断代码、栈保护、显示／音频 DMA 与调制解调器睡眠。
天气仍使用证书验证的 HTTPS 和动态 TLS 缓冲。镜像变小、设备申请减少不能证明实际电流降低，

### 有上限的诊断约定

## Agent 提醒约定

适配器位于电脑端，复用配对传输和音频任务；设备状态固定、有界、支持过期和去重。不转发会话内容，不干预审批。保持语音优先与实体按键原有含义。详见[接入与内存约定](agents.zh_CN.md)。

仅接入需要人工关注的回调。首条立即转发，同一 Agent／已知会话后续一秒内跨类型忽略，不延长窗口；其他会话和 Agent 互不影响。不合并缺失的会话标识，不增加生命周期 Hook、延迟候选或元数据补查。保留精确事件重试去重，电脑端记录有界。泛化空闲和单次工具失败不作为新的人工处理请求。

用五秒自动消失的紧凑非模态浮窗展示提醒，保留未覆盖的页面内容及持续更新。
任意实体按键按下即关闭浮窗，并继续执行同一次手势。不增加专用关闭操作、背景遮罩、
页面截图、新任务或更大的 LVGL 池。复用原有字体，在页面内容之后绘制，保持语音随时
可用，交付前测量绘制峰值及反复显示／关闭后的留存分配。
