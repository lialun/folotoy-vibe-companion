## 状态、任务与协议

`main/vibe/model.c` 不依赖 ESP，可在主机测试。
控制任务消费有界按键／网络队列，按钮回调只入队。
短按从抬起且未长按的手势生成，长按下键不会误发回车，快速两次短按仍是两次操作。
LVGL 全部使用官方锁，屏幕对象保留到应用结束，没有后台任务引用已删除页面。

单一音频任务串行管理麦克风、电台、提示音与 codec。
空闲时走官方 ES8311 休眠路径并停止 I2S。
电台会话退出时关闭 HTTP 和解码器，再交还音频资源。
番茄钟使用单调时间截止点，不受页面、网络、校时影响。
计时跨页面保留，不跨断电保留；偏好设置持久化到 NVS。

UDP 33333 保留 1 音频、2 JSON 事件、3 电脑信标、4 ping。
音频包 807 字节：类型、序号、`0x80`、804 字节独立 IMA 块，16kHz 单声道、每块 100ms。
丢包影响限制在独立块；关键事件带事件 ID 重发三次，Mac 去重，包括回车。
配置请求带 ID、范围校验、明确回复和有限重试；相同配置不会重复写 NVS，保存失败会反馈。

首次配对使用设备六位码和每台 Mac 随机令牌。
后续控制和就绪消息验证令牌，令牌保存到 Mac 当前账户本地配置文件与设备 NVS，当前 App 不调用钥匙串。
JSON 限制长度与嵌套深度。协议适用于可信局域网，不是加密传输。
源码和应用日志不保存录音、Wi-Fi 密码或令牌。
配网 HTTP 仅在热点开启时存在，只接受热点网卡上的请求，页面只填写 Wi-Fi。
密码在连接成功后才保存。
修订后的配网热点无需密码。Captive DNS 只绑定热点地址，只在配网时由现有网络任务轮询，
配合 DHCP 页面提示和手机探测请求的 HTTP 跳转。HTTP 网卡检查同时接受 IPv4 和 IPv4 映射的 IPv6；
原来只判断 IPv4，错误拒绝了双栈 HTTP 服务上的正常请求。
主机测试覆盖两种地址、有界 DNS／EDNS 回包及异常报文。
手机表单使用同源自定义提交标头、明确的连接／失败状态，并保留手动打开网址的兜底。
联网且 NVS 保存成功后，给手机三秒读取结果，然后设备自动关闭热点并返回首页，不依赖手机再次请求。
失败时保留原表单。页面会尝试关闭自身，普通浏览器标签页可能保留成功提示。
用户已在真实手机确认自动弹窗。
仅启动后一直未联网时自动提供一次热点配网。正常使用中断 Wi-Fi 会留在首页重连，
不会替换当前页面；设备设置中仍可主动进入配网。

Mac 在结束、断开、输入超时、睡眠和退出时释放语音按键；结束时保留短暂音频排空时间，避免切掉尾字。
App 不采集或全局替换电脑麦克风，由微信输入法显式选择 BlackHole。

## 功耗策略

不启用 BLE、空闲录音、持续音量采样、动画或云端长连接。
空闲 Wi-Fi 使用最小 modem sleep，申请 ESP-IDF 自动 light sleep 和 tickless idle。
语音期间暂时关闭 modem sleep 降低延迟，结束恢复。
未发现设备时每两秒发现一次，配对后每五秒单播信标与 ping。
天气每十五分钟刷新，失败退避，只在音频空闲时开始请求。
配对、修改设置和按键动作属于低频通信。

ADC 按键轮询与显示基础设施仍会周期唤醒 CPU，USB 调试也可能影响休眠；这些设计不是续航实测结论。
需电池供电测量息屏、亮屏、语音和电台电流。
不提供软件关机入口。Agent 通知与低功耗唤醒设计暂不实现。

### 自适应 FIFO 与紧凑收音机界面

所有支持的收音机格式现在都尝试三块独立的 8 KiB FIFO，不足则退回两块或一块。
准入发生在首帧实际解码和 I2S 初始化之后。先申请必需的 5 KiB 读取栈，再申请可选
FIFO 块；可选块申请失败时保留已取得的较小 FIFO。分配后再次检查实际空闲堆，
必要时释放可选块，保留原有 16 KiB 网络／控制余量。未新增收音机任务、栈或常驻
PCM 缓冲。这套预算提高容错，不保证会话后续所有分配成功，也不能解决音源不可用。

收音机模块采用居中的当前台、调谐刻度、播放状态和较小的下一台预览。仅换台时

## Wi-Fi、BLE 与电脑使用权

连接架构见[连接约定](connections.zh_CN.md)。设备记住八台电脑的身份，同一时刻只允许
一台拥有使用权。Wi-Fi 与 BLE 共用每台电脑的凭据；最多保留两条 BLE 连接，供当前
使用者及临时接管使用。健康链路保持不变，故障转移先考虑同一台电脑，再考虑其他已配对电脑。

协议 3 控制同时绑定设备开机标识和使用权租约，拒绝旧接管、旧设置写入和上次开机的消息。
桌面端校验完整版本字段、拒绝协议降级，并通过有效使用权广播确认接管。无线开关操作在
原确认包丢失时，可通过剩余链路的新状态确认；其他旧链路操作立即丢弃。凭设备配对码
恢复单台电脑凭据时，不改变其他配对记录。

BLE 适配器保留已恢复的订阅，拒绝旧连接句柄，限制分片重组和 HCI 重试，并在关闭时先
等待主机任务结束。ESP-IDF 5.5.3 关闭按块动态内存池、保留动态上下文，以安全释放协议栈。
BLE 在 Wi-Fi／UI 常驻分配完成后启动。网络任务通过 eventfd 唤醒，兼容纯 BLE，不新增轮询任务。

## 电脑转发收音机与诊断记录

收音机由当前电脑按需启动独立 FFmpeg 子进程解码，通用架构解码器附带对应 LGPL 源码
和构建脚本。设备接收独立的 50 ms、24 kHz 单声道 IMA ADPCM 块，以累计额度控制
15,704／23,556 字节分段 FIFO。保留常驻语音 PCM 和 16 KiB 控制／网络余量。
语音抢占停止转发并释放收音机会话的临时分配。

设备诊断环占 200 字节。相对仅转发收音机的参考构建，DRAM data 与 BSS 共增加
304 字节；不增加诊断采样任务、周期定时器或 Flash 日志。桌面最多保留 500 条／512 KiB
类型化记录，补取离线事件、去除重试重复项，只导出允许字段。原始链接、凭据、网络地址、
解码器标准错误和对话正文不进入记录。

连接状态独立于语音就绪。Wi-Fi 与 BLE 分别展示，权限／驱动错误放在语音区。
设备统计和诊断历史共用入口。Agent 安装状态读取原生配置；DSH 检查 bundle 注册和
已安装文件，不依赖历史事件。非当前电脑打开窗口不会重新占用已释放的 BLE 连接。
