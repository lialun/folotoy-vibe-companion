# Vibe 伴侣 v1.0.2

**多电脑自动接续，Wi-Fi 配置更可靠。**

带着 Vibe 伴侣往返家与公司，分别确认过的电脑可以自动恢复连接。原电脑仍在使用时保持当前连接；需要立即换电脑，也可以主动申请，在设备上确认切换。

## 本次更新

- **记住多台电脑**：设备最多保存四台电脑的授权，首次确认后保留各自凭据，无需每次换机重新配对。
- **空闲后自动接续**：当前电脑退出或连接失效、会话释放后，其他已授权电脑可以自动连接。
- **切换由你决定**：另一台电脑不会自动抢占正在使用的设备。主动申请换机时，设备显示电脑名称；拒绝或取消后，原连接继续可用。
- **修复 Wi-Fi 配置故障**：改善手机已连接设备热点，但配置页或网络列表无法加载的问题。配网期间暂时释放蓝牙资源，完成或退出后自动恢复。
- **连接进度更清楚**：提交 Wi-Fi 信息后立即显示连接状态，防止重复提交；失败后可以修改并重试。
- **简化操作提示**：连接确认页只保留“确认／取消”；音频驱动显示改为“已检测到 BlackHole 2ch”，避免与当前麦克风选择混淆。

## 安装与升级

请同时升级 **1.0.2 桌面端与设备固件**，以使用完整的多电脑自动接续功能。

桌面端“解除配对”仅移除当前电脑；设备上的“解除配对”清除所有电脑授权。两项操作均保留 Wi-Fi 设置。

提供 Apple Silicon／Intel 通用 DMG、ZIP，安装步骤见 `INSTALL.zh_CN.txt`。更新后，macOS 可能要求刷新 App 原有的辅助功能授权。使用期间保持电脑唤醒、App 运行。

完整固件 `FoloToy-AI-Passport-full.bin` 从 `0x0` 写入，可能重置 Wi-Fi、设备设置与配对记录。需要保留配置的开发者，请按仓库固件布局文档使用兼容的应用分区升级方式。下载后核对 `SHA256SUMS.txt`。

## 从源码构建

激活 ESP-IDF 5.5.3 后运行 `./tools/validate.sh`，完成主机测试、固件构建与完整镜像验证。macOS 运行 `bash macos/build.sh`，生成通用桌面端并执行原生测试。GitHub 发布包由 Actions 对发布标签重新构建，通过发布门禁后上传。
