# Vibe 伴侣 v1.0.1

## 本次更新

**语音稳定性大幅优化，让不同网络条件下的输入更稳、更连贯。**

本次升级围绕语音传输、缓存、补发和连续播放进行了系统性重构与优化。Wi-Fi＋蓝牙双链路互相补位，单 Wi-Fi、单蓝牙也有更完善的短时恢复，减少网络抖动和临时发送拥堵带来的中断、卡住及漏音，提升日常语音交互的可用性。

- **双链路更好地协同**：两路独立重试，电脑合并、去重并确认已收到的音频；已确认的数据不再让慢链路反复发送，占用恢复空间。
- **单链路更能承受短暂抖动**：扩大有界语音缓存，改进缺块补发与连续播放。实际缓存按设备启动时的可用内存选择，本机为两秒；缓存不额外增加正常起音预缓冲。
- **语音优先使用内存**：收音机与语音共用大块音频工作区，录音时让出缓存，语音收尾后再恢复电台。
- **回车恢复正常且保留独立保护**：修复时钟偏差可能持续拦截回车的问题；保留明确下键指令、去重和取消隔离，语音停止、超时或恢复不会自行生成回车。
- **录音生命周期更清晰**：统一开始、结束、取消与输出排空，隔离旧录音、旧回调及过期补发；休眠或全断链后不自动续录。

## 安装与升级

请同时升级 **1.0.1 桌面端与设备固件**，启用完整的接收确认、缓存交接和输入保护。旧端保留兼容的原有协议行为。

桌面端提供 Apple Silicon／Intel 通用 DMG、ZIP；安装步骤见 `INSTALL.zh_CN.txt`。更新后，macOS 可能要求刷新 App 原有的辅助功能授权。使用期间保持电脑唤醒、App 运行。

完整固件 `FoloToy-AI-Passport-full.bin` 从 `0x0` 写入，可能重置设备设置与配对。需要保留配置的开发者，请按仓库固件布局文档使用兼容的应用分区升级方式。下载后核对 `SHA256SUMS.txt`。

安装包采用免费 ad-hoc 签名，未经过 Apple 公证。Agent 提醒、额度、天气、番茄钟与收音机功能继续保留。

## 验证与已知限制

完整本地门禁、固件镜像验证及 Mac 原生测试通过。实机自动检查已记录 33 项，其中 31 项通过，覆盖单链路、双链路、补发、路径变化、长录音及收音机交接；另有一次测试准备超时。上述测试使用真实音频采集、无线传输与 CoreAudio，并模拟键盘输出。用户已反馈当前语音输入效果改善、回车正常；真实回车换行另已确认。

仍有以下边界，未因发布而删除：

- 很弱的单 Wi-Fi 仍可能音频超时。弱 Wi-Fi 叠加主动丢弃首份副本的压力测试中，音频全部恢复，但出现过一次 20 ms 播放空档。
- 两种无线共用射频，底层调度仍可能相互影响；不保证双链路在每种环境都优于单链路，也不承诺零丢包。
- 收音机经蓝牙传输、重传积压时仍可能卡顿。

耗电／电流、全新系统、实体 Apple Silicon／最低 macOS，以及多台实体电脑／设备的完整验收尚未完成。自动测试不等于输入法识别准确率或主观听感验证。

## 从源码构建

激活 ESP-IDF 5.5.3 后运行 `./tools/validate.sh`，完成主机测试、固件构建与完整镜像验证。`./tools/validate.sh --firmware` 只运行固件部分。macOS 运行 `bash macos/build.sh`，生成通用桌面端并执行原生测试。GitHub 发布包由 Actions 对发布标签重新构建，通过全部发布门禁后上传。
