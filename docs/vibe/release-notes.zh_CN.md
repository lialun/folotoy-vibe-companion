# Vibe 伴侣 v1.0.0

## 本次更新

Wi-Fi 与蓝牙均已授权连接时，语音同时通过两条链路传输。电脑按录音和音频序号合并、去重，
一条链路断开时，可以由仍然可用的另一条继续承载，无需重新开始输入。

单 Wi-Fi、单蓝牙也新增有限恢复能力：设备保留短时压缩音频历史，临时发送失败时重试，
电脑发现缺块时请求补发。链路选择能够容忍短暂抖动；语音结束后保留尾字，等待输出完成再执行排队的回车。
全断链或电脑休眠时安全停止，不会自动开始新一段录音。

恢复具有明确的内存、次数与延迟上限。持续中断仍可能丢失音频，本版不承诺任何环境下零丢包。

## 已有功能

- 语音输入与回车、Agent 提醒、额度与天气轮播、番茄钟、收音机及桌面端设备设置。
- 七种内置 Agent 提醒集成；Codex、Claude Code、OpenCode Go 额度采集；自定义 Agent 提醒与额度回调。
- 蓝牙、Wi-Fi 发现合并为一条设备记录，电脑发起连接、设备确认，换电脑也在设备上确认。
- 电脑解码电台，通过蓝牙或 Wi-Fi 播放，语音输入时暂停、结束后恢复。
- Apple Silicon／Intel 通用桌面端、中英文安装说明、第三方声明与验证过的完整固件。

## 安装与升级

完整语音恢复能力需要将桌面端和设备固件一起升级到 v1.0.0；旧端仍保持原有语音行为。
安装与权限设置见 `INSTALL.zh_CN.txt` 或 `INSTALL.txt`。使用期间保持电脑唤醒、App 运行。
更新后，系统可能要求刷新 App 原有的辅助功能授权。

完整固件 `FoloToy-AI-Passport-full.bin` 从 `0x0` 写入，可能重置已保存设置与配对。
需要保留配置的开发者，请按源码固件布局文档使用兼容的应用分区升级方式。
下载后请核对 `SHA256SUMS.txt`。

安装包采用免费 ad-hoc 签名，未经过 Apple 公证。桌面端目前支持 macOS，一台设备同时授权一台电脑。
在线电台与额度由电脑获取；额度是否可用取决于 Agent 已有登录、套餐与提供的字段。

## 已知问题

收音机改走蓝牙且重传积压时仍可能卡顿，本版未包含电台调度修复。

## 从源码构建

激活 ESP-IDF 5.5.3 后运行 `./tools/validate.sh`，完成主机测试、隔离固件构建与完整镜像校验。
`./tools/validate.sh --firmware` 只执行固件部分，输出验证后的 `build/FoloToy-AI-Passport-full.bin`。
macOS 运行 `bash macos/build.sh`，生成通用桌面端、执行原生测试并打包 DMG／ZIP。

## 验证范围

语音实现已通过完整本地门禁和 Mac 原生测试。实机自动检查 27/27 通过，覆盖单 Wi-Fi、单蓝牙、
注入丢包、临时发送失败、双链路补发、全断停止与恢复，以及临时缓存释放。
其中八段连续性录音收到全部 1,750 块采集音频，没有播放缺块。
用户已确认安装版本与常规固件的长短语音、松开后立即回车均正常。
双链路开发期间已人工验证休眠停止、唤醒重连与恢复输入，清理逻辑也有原生回归。
这些结果仅覆盖实际测试条件，不代表所有无线环境。
