# Vibe 伴侣 v0.9.0

## 本次更新

Agent 额度加入桌边体验，与语音输入、任务提醒一起使用。桌面端通过已有集成
采集 Codex、Claude Code、OpenCode Go 的剩余额度与重置时间；Go 分别展示
五小时、每周、每月三个窗口，不用金额余额代替套餐额度。

额度页排在天气之前，共用统一页码。三个比例周期可以同屏展示。近期使用时
通常每五分钟采集一次，空闲十分钟停止，失败后自动退避。样本十五分三十秒后
过期，重连不会续期；获取不到时不显示错误卡片。

桌面端新增“接入自己的 Agent”。复制提示词即可为自己的 Agent 接入本机任务
提醒和真实额度回调。自定义 Agent 保留自己的展示名称，不向设备发送对话正文
或凭据。字段限制和回调要求见源码文档。

本次还改善了蓝牙通知处理，避免系统切换无关订阅时关闭应用通道。请配套更新
同一版本的固件和桌面 App。

## 包含功能

- 语音输入与回车、Agent 任务提醒、额度与天气轮播、番茄钟、收音机及外观设置。
- 七款内置 Agent 提醒集成，Codex、Claude Code、OpenCode Go 额度采集，
  以及本机自定义 Agent 提醒和额度回调。
- 蓝牙与 Wi-Fi 发现合并为一个设备条目，电脑发起连接、设备确认，两条链路可同时连接。
- 电脑解码电台，通过任一链路发送；语音输入时暂停，结束后恢复。
- Apple Silicon／Intel 通用 macOS App、双语安装指南、第三方声明及已验证合并固件。

## 安装与升级

安装同一 Release 中的固件与 App。安装、授权、输入法与连接设置见
`INSTALL.zh_CN.txt` 或 `INSTALL.txt`。已有 Agent 集成出现“更新集成”时请更新，
再重启或重新载入 Agent 会话，并完成 Agent 内的信任确认。额度内容取决于当前
登录套餐及 Agent 提供的字段。

合并固件 `FoloToy-AI-Passport-full.bin` 从 `0x0` 写入，可能重置设备设置。
需要保留设置的开发者请按源码中的兼容应用分区升级流程操作。核对 `SHA256SUMS.txt`。

安装包使用免费的 ad-hoc 签名，未经 Apple 公证。首次打开或更新可能需要系统确认，
并刷新原有辅助功能授权。

## 从源码构建

激活 ESP-IDF 5.5.3 后运行 `./tools/validate.sh`，完成主机测试、隔离固件构建与
合并镜像验证。仅验证固件可运行 `./tools/validate.sh --firmware`，输出
`build/FoloToy-AI-Passport-full.bin`。在 macOS 运行 `bash macos/build.sh`，
生成通用 App、原生测试、DMG 与 ZIP。

## 验证范围

本机完成了固件构建、主机／原生测试、深浅主题真实字体渲染、Codex 实际额度、
已安装自定义 helper 回调，以及 Wi-Fi／BLE 实机额度收发、重试不续期与条件清理。
自定义提醒收到设备回执，额度样本在桌面端展示后按原有效期消失。

Claude Code 与 OpenCode Go 适配器使用接口及响应样本检查，本机没有这两项服务的
真实订阅账号。新增三窗口页面已检查字体渲染，尚无单独的实机目视确认。
耗电、干净系统安装、Apple Silicon／最低 macOS、多台实体电脑／设备测试不在
本机已完成范围内。此前语音、回车、电台与恢复、重新配对及手机 Wi-Fi 验收见上一版本。

当前桌面端支持 macOS。一台设备同时授权一台电脑，确认换机后替换原授权。
使用时保持电脑唤醒、App 运行；收音机和在线额度由电脑联网获取。
