# Vibe 伴侣 · 语音输入与额度管理

## 玩法介绍

最多记住四台已确认的电脑，带着设备往返家与公司，空闲后自动接续。正在使用的电脑保持连接，需要立即换机时在设备上确认。

语音输入、额度管理，你的自定义 Vibe 伴侣。配套桌面 App，让设备连接、语音配置与 Agent 接入更直观。

语音稳定性大幅优化，让多种网络条件下的输入更稳、更连贯。Wi-Fi＋蓝牙双链路聚合，让语音输入更稳、更连贯。两条链路同时传输，电脑自动合并去重；一条短暂丢包，另一条补位，一条断开时可由仍然可用的另一条继续承载。减少中断与漏字，让表达更顺畅。仅使用一条链路时，也有短时缓存与缺块补发。

把 Codex、Claude Code、OpenCode Go 等常用 Agent 的剩余额度与任务提醒，集中到桌边的 AI 护照上。额度余量、重置时间与任务动态，一目了然。

用语音表达想法，让文字输入更自然。任务完成、等待审批或需要回答时，设备亮屏提醒，减少反复查看对话窗口。

蓝牙与 Wi-Fi 双连接，适配多种使用环境。常用 Agent 一键集成，自己的 Agent 也能接入，让伴侣贴合你的工作流。

专注时用番茄钟，休息时听收音机，天气随手可看。从工作到日常，打造属于你的桌边搭档。

## 使用说明

1. 刷入固件，安装并打开同版本 Vibe 伴侣桌面 App：https://github.com/lialun/folotoy-vibe-companion/releases/latest
2. 选择蓝牙或 Wi-Fi，在 App 点击设备“连接”，再在设备上确认电脑名称。
3. 开启需要的功能：在“Agent 提醒”安装集成；语音输入跟随 App 内引导完成设置。自己的 Agent 可复制“接入自己的 Agent”中的提示词，接入提醒与额度回调。

Wi-Fi 设置：进入设备“功能 → 设备设置 → Wi-Fi”，手机连接屏幕显示的 Vibe-Setup 热点，稍后弹出配置页；10 秒未弹出时，用浏览器打开 http://192.168.4.1/。刷新列表、选择网络并保存；页面显示连接进度，完成后设备返回首页。换网络时重新进入此页。Wi-Fi 需要电脑与设备在可互通的局域网，蓝牙可直接连接电脑。配置 Wi-Fi 期间蓝牙暂时断开，完成或退出后自动恢复。

每台电脑首次连接都在设备上确认，最多记住四台。原电脑退出或失联、会话释放后，其他已确认电脑自动连接；原电脑仍在使用时，可在另一台 App 点击连接，在设备上确认切换。

首页上键进行语音输入，下键回车；其他页面按右侧实体键提示操作。除首页语音和回车外，黑屏时首次按键仅亮屏。

使用时保持电脑唤醒、App 运行；输入法语音识别、收音机与在线额度可能需要电脑联网。额度依赖已有 Agent 登录与套餐，过期数据自动隐藏。

升级请同时更新桌面端与固件。完整刷机可能重置设备设置与配对；桌面端更新可能需要刷新辅助功能授权。
