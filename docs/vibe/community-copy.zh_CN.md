# Vibe 伴侣 · 语音输入与额度管理

## 玩法介绍

语音输入、额度管理，你的自定义 Vibe 伴侣。配套桌面 App，让设备连接、语音配置与 Agent 接入更直观。

把 Codex、Claude Code、OpenCode Go 等常用 Agent 的剩余额度与任务提醒，集中到桌边的 AI 护照上。额度余量、重置时间与任务动态，一目了然。

用语音表达想法，让文字输入更自然。任务完成、等待审批或需要回答时，设备亮屏提醒，减少反复查看对话窗口。

蓝牙与 Wi-Fi 双连接，适配多种使用环境。常用 Agent 一键集成，自己的 Agent 也能接入，让伴侣贴合你的工作流。

专注时用番茄钟，休息时听收音机，天气随手可看。从工作到日常，打造属于你的桌边搭档。

## 使用说明

1. 刷入固件，安装并打开 Vibe 伴侣桌面 App。
2. 选择蓝牙或 Wi-Fi，在 App 点击设备“连接”，再在设备上确认。
3. 开启想用的功能：在“Agent 提醒”安装集成；语音输入跟随 App 内引导完成设置。

接入自己的 Agent：打开“Agent 提醒 → 接入自己的 Agent”，复制提示词交给大模型。

桌面端下载：https://github.com/lialun/folotoy-vibe-companion/releases
使用时保持电脑唤醒、App 运行；收音机与在线额度由电脑联网获取。
