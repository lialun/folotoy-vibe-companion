# 安装与使用 Vibe 伴侣

项目介绍见[根 README](../../README.md)。本指南说明设备配置与使用；
[Mac 安装指南](install.zh_CN.md)说明客户端，[Agent 接入](agents.zh_CN.md)说明 Hook 和插件。

## 首次配置

### 安装固件

使用**同一 GitHub Release** 中配套的固件和桌面 App。目标硬件为 FoloToy AI Passport：
ESP32-C3、8 MB Flash、240 × 320 彩屏，不适用于任意 ESP32 开发板。

设备开机后通过 USB 数据线连接电脑，用支持 Web Serial 的浏览器打开
[FoloToy 官方刷机工具](https://ai-passport.folotoy.cn/tools/web-flasher/)，选择**安装本地固件**，
使用下载的 `FoloToy-AI-Passport-full.bin`。合并固件从 **`0x0`** 写入。全新安装替换原固件，
可能重置已有设置，不能把应用分区单独的镜像写到 `0x0`。

开发者如需保留配置，按[固件布局](../development/engineering/firmware-layout.zh_CN.md)
选择兼容的应用分区升级。完整安装镜像不承诺保留旧数据。

### 连接 Wi-Fi

首次开机，用手机连接设备屏幕显示的无密码热点 `Vibe-Setup-...`。手机应自动打开配网
页面，未弹出时打开 `http://192.168.4.1`。选择 **2.4 GHz** 网络、输入密码并连接。
连接和保存成功后自动关闭热点并返回首页，不需要第二次确认；手机不允许自动关闭时，
浏览器标签页可能保留成功提示。

设备最多记住五个网络。开机、断线时先尝试上次成功的网络，再自动尝试其他保存网络。
添加新网络时，在设备进入**功能 → 设备设置 → 重新配网**。手机页面可以免输密码连接
已保存网络、更新密码或忘记网络。忘记当前网络只删除记录，不立即中断当前连接。
无需填写昵称、头像等其他资料。

### 配对电脑

按 [Mac 指南](install.zh_CN.md)安装 App、BlackHole 2ch 和兼容输入法。设备和电脑需在
可互通的局域网；访客网络／客户端隔离可能阻止发现。客户端自动使用空闲端口。

在 App 输入设备显示的六位配对码。输入法麦克风选 **BlackHole 2ch**，“按住说话”快捷键
与客户端一致。快捷键控制权限授予 **App 本身**，之前给终端的权限不会继承。
当前一台设备配对一台电脑，配对保存在当前账户的私有文件中，不使用钥匙串。

点到输入框，按住上键说话，松开结束，短按下键回车。包括合盖使用在内，电脑需保持唤醒。

## 三个按键

从上到下依次是**上键、下键、设置键**。下键实际在中间，设置键在最下方；BSP 中的 `OK`
就是设置键。

| 页面 | 上键 | 下键 | 设置键 |
| --- | --- | --- | --- |
| 首页／天气 | 按住语音，松开结束 | 短按回车，长按进入番茄准备页 | 短按下一页天气，长按功能 |
| 番茄钟 | 按住语音 | 短按回车，长按退出 | 短按开始／暂停／继续，长按功能 |
| 收音机 | 按住语音，松开重连收听 | 短按回车，长按退出确认 | 短按下一台，长按功能 |
| 退出确认 | 短按取消 | 短按确认退出 | 无动作 |
| 功能／设置 | 上选／增加 | 下选／减少 | 短按进入／编辑／确认，长按返回 |

同一次长按松手后不会额外回车或确认退出。右侧窄栏随页面提示当前功能。

首页息屏时，上键一次手势即可唤醒并语音；下键一次手势即可唤醒并执行短按／长按。
天气页设置键只唤醒，不顺带翻页；番茄内设置键可一次唤醒并开始／暂停／继续。
其他页面先由首次按键唤醒，再导航。

## 番茄钟

天气页长按下键进入准备状态，短按设置键开始、暂停或继续，语音和回车仍可用。
完成后响铃、显示十秒完成状态，随后停在下一阶段。**每个阶段都由你短按设置键开始**，
不会自动启动。

长按下键退出：未开始的阶段直接退出；运行或暂停时打开确认页，上键取消，下键结束。
运行中的倒计时在退出确认和设备设置内继续，取消保留原状态。修改时长只影响下一阶段，
不会改变当前截止时间。

## 天气

天气固定显示，初始地区为北京，可在客户端选择城市。短按设置键阅读四页缓存信息，
不会自动翻页；息屏后唤醒回到当前天气。

| 页面 | 内容 |
| --- | --- |
| 当前天气 | 温度、天气、最高／最低温、体感、湿度、今日最高 UV 和等级 |
| 未来六小时 | 共用时间列的温度曲线、降雨概率和降水量 |
| 空气与风力 | 美标 AQI、PM2.5 浓度、风力、阵风和每日最大风速 |
| 三日预报 | 每日天气图标、最高／最低温和降雨信息 |

数据来自 [Open-Meteo](https://open-meteo.com/)，通常每十五分钟更新，不依赖电脑。
缺失值显示“—”，天气过期保留更新时间，空气超过三十分钟则不继续显示旧值。
风速显示蒲福风级，**美标 AQI 不等于中国 AQI**，PM2.5 单位为 µg/m³。
UV 同时显示数值和等级，不只靠颜色。翻页不联网、不写 Flash。

## 收音机

设备进入**功能 → 收音机**。在客户端通过“推荐”“搜索”“自定义”加入“我的电台”，
拖动排序后保存，最多二十台。搜索允许空内容，“中文”条件可以取消。
自定义地址应为受支持的公开音频流／播放列表，不是网页。客户端加入前检测媒体格式；
Mac 检测通过不等于一定能在 ESP32 播放。

短按设置键下一台。按住上键时释放收音资源，优先录音；松开后按照之前的收听意图
重新连接直播，不从此前缓存的时刻继续。没有单独的暂停入口。长按下键打开退出确认，
确认前继续播放；上键取消不中断，下键确认才停止并退出。

收听时可以进入设备设置调音量，或从客户端**只改音量**保存，即时生效。
其他设置改动需先停止音频。播放效果受格式、服务器可用性、网络抖动和设备内存影响。

## 设置与主题

客户端配置亮度、音量、3–60 秒息屏、麦克风增益、番茄时长、天气城市、电台和主题。
麦克风增益可悬停问号查看含义和调整建议。关闭窗口后 App 留在菜单栏，从菜单“退出”
才停止运行。

设备保存的设置是最终值。客户端连接时读取，并接收后续变化；未保存的本地修改保留
为草稿，保存只写改过的项，以设备成功回复为准。“重新读取”放弃草稿。
固件更新不会用默认值覆盖已有配置。

新设备默认亮度 50%、音量 80%、息屏 15 秒、专注／休息 25／5 分钟，08:00 亮色、
21:00 暗色。客户端或**设备设置 → 屏幕主题**可切换暗色、亮色、自动。
编辑设置时有描边、反色数值和箭头提示，主题与亮度分别控制。

日期、时间和定时主题使用同一个设备时钟。Wi-Fi 可独立校时，客户端也会同步时间。
尚无有效时间时不显示真实日期时间，自动主题暂用暗色。本机没有能在彻底断电后继续
计时的电池时钟。番茄使用单调计时，不受校时影响。

解除电脑配对只修改配对状态，保留 Wi-Fi 和其他配置，新电脑重新配对即可。
设备不提供软件关机。

## Agent 提醒与待机诊断

在“Agent 提醒”安装所需集成，按[接入与验证指南](agents.zh_CN.md)确认实际覆盖。
提醒亮屏响铃，浮窗覆盖当前页面五秒；实体按键关闭浮窗并继续同一次手势，不把
Session ID 当作会话名称显示。

测试待机时，打开“连接与语音 → 待机诊断”，重新计时、拔掉 USB、息屏运行五到十分钟，
再读取统计。统计包含息屏／浅睡时长和电源锁，不是电流测量。连接 USB 本身可能阻止
自动浅睡，重新计时不清除开机以来的电源锁记录。面板还显示动态堆的已用、可用、
最大空闲块和历史最低可用空间。“复制报告”导出设备上报的计数，供排查使用，不持续采样。
电量百分比是电量计的估算，不等于校准过的电流或容量读数。

## 常见问题

- **找不到设备：** 检查局域网互通、本地网络权限、VPN／防火墙、Wi-Fi 客户端隔离。
  可重新打开客户端或重试连接。
- **不能触发语音：** 先在普通输入框测试实体快捷键，再检查输入法、快捷键一致性、
  BlackHole 和 App 授权。其他软件占用安全键盘输入时，实体和模拟快捷键都可能受影响。
- **权限打开仍未就绪：** 返回 App 等待自动检查。临时签名更新可能使旧权限失效，
  按 Mac 指南重新添加授权条目。
- **电台失败：** 换一个已知电台，核对地址与格式；反馈时记录电台名和屏幕错误。

可复现问题按[反馈指南](../../.github/SUPPORT.zh_CN.md)提交。
